# Contributing

Anyone can add or fix a listing. Some ground rules:

- One listing per product. If it runs on several chains, put it in `shared/` once.
- Write the description from the project's own docs or site. No "best", "leading" or price talk.
- Official links only. No referral links or URL shorteners.
- Logo and cover from the project's site or brand kit.
- Put at least one person who can speak for the product in `maintainers`. Later changes to the listing need their OK or ours.

We remove listings for products that got compromised, were abandoned, or keep failing the weekly link check. Something that shut down can stay as `sunset`.
