# Contributing

Anyone can add or fix a listing. Some ground rules:

- One listing per product. If it runs on several chains, put it in `shared/` once.
- Write the description from the project's own docs or site. No "best", "leading" or price talk.
- Official links only. No referral links or URL shorteners.
- Logo and cover from the project's site or brand kit. The logo is a square PNG, ideally opaque with its own background; the cover is optional.
- Changes to an existing listing need an OK from the person who added it, from the project, or from us.

We remove listings for products that got compromised or were abandoned, and review any app the daily check has not reached for 30 days.
